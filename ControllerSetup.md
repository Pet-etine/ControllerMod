## 2. Controller Button Mappings

### Movement & Camera

- **Left Joystick:** `W` / `A` / `S` / `D` (Movement)
- **Left Stick Click (L3):**
  - **Press:** `Tab` (Select nearest enemy)
  - **Double Press:** `Delete` (Select nearest object)
- **Right Joystick:** Joystick Mouse (Camera control)
- **Right Stick Click (R3):** Right Mouse Click (Target / Interact)

### Action Bars & Modifiers

The UI uses shoulder buttons as modifier keys to access all 32 quickslots across 4 action bars:

| Controller Button | Key Binding | In-Game Action / Function |
|-------------------|-------------|---------------------------|
| **Face Buttons (A, B, X, Y)** | `1`, `2`, `3`, `4` | Main Skill Slots 1–4 |
| **D-Pad (Up, Right, Down, Left)** | `5`, `6`, `7`, `8` | Main Skill Slots 5–8 |
| **Left Bumper (LB)** | `Shift` | Modifier Key (Shift Bar) |
| **Right Bumper (RB)** | `Control` | Modifier Key (Control Bar) |
| **Left Trigger (LT)** | `Alt` | Modifier Key (Alt Bar) |
| **Right Trigger (RT)** | Left Mouse Click | Target Selection / Drag-and-Drop |

### System & Menus

- **View / Select Button (Left Menu):**
  - **Press:** `M` (Map)
  - **Long Press:** `C` (Character Panel)
  - **Double Press:** `L` (Quest Log)

- **Menu / Start Button (Right Menu):**
  - **Press:** `I` (Inventory / Bags)
  - **Long Press:** `Escape` (Main Menu / Cancel)
  - **Double Press:** `K` (Skill Panel)

## 3. Configuring Multi-Action Buttons in Steam

To assign multiple commands (Press, Long Press, Double Press) to a single button (such as Select or Start):

1. Open **Steam Controller Settings** for LOTRO.
2. Select the button you wish to configure (for example, **Select Button**).
3. Set **Command 1** to **Regular Press** and assign the primary key (for example, `M`).
4. Click the **Gear Icon** next to Command 1 and choose **Add Extra Command**.
5. Change the activator type for **Command 2** to **Long Press** and assign the second key (for example, `C`).
6. Click **Add Extra Command** again, change the activator type for **Command 3** to **Double Press**, and assign the third key (for example, `L`).

Repeat the same process for any other buttons that require multiple actions.

## 4. In-Game Skill Assignment (Drag-and-Drop)

1. Open your **Skill Panel** (`K` or double-press the **Start** button).
2. Use the **Right Joystick** to move the cursor over a skill icon.
3. Hold **Right Trigger (RT)** to pick up the skill.
4. Drag the icon onto the desired **ControllerMod** quickslot.
5. Release **RT** to place the skill.

### Repositioning the Overlay

To move the ControllerMod overlay:

1. Hold **Ctrl**.
2. Left-click anywhere on the ControllerMod frame.
3. Drag it to the desired position.
4. Release the mouse button to save the new position automatically.
